# pizza_app

CPSC 5340 — Assignment 2

A single-screen pizza ordering app. Users choose pizzas and quantities,
pick a size, add extras (extra cheese, dipping sauces), set a tip with a
slider, and confirm the order in a dialog.

## New UI elements explored
- `Slider` (tip selector) — `lib/widgettip_slider.dart`
- `SingleChildScrollView` (scrolling / landscape support) — `lib/screens/order_screen.dart`
- `Divider` — `lib/widgets/extras_panel.dart`, `lib/widgets/order_summary.dart`
